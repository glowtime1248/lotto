# 🎱 로또 번호 추첨기

버튼을 누르면 1~45 중 겹치지 않는 번호 6개를 뽑아주는 웹앱입니다.

- 만든 사람: lottolee
- 만든 방법: Claude Code에게 말로 요청해서 만듦 (코드 직접 작성 0줄)
- 사용 기술: HTML, CSS, JavaScript (index.html 파일 하나)
- 배포 주소: https://lottolee.vercel.app

## 기능
- 번호 뽑기 버튼
- 번호대별 색깔 공 (1~10 노랑, 11~20 파랑, 21~30 빨강, 31~40 회색, 41~45 초록)
- 휴대폰 화면 지원

## Phrase Palace (english/index.html)

교재 사진 → 표현 추출 → 카드 · 기억궁전 스토리 · 디테일 함정 퀴즈 · 문장 조립 · 말하기 · AI 회화 · 핸즈프리 듣기, 그리고 간격 반복(SM-2) 복습으로 영어 숙어를 외우는 웹앱입니다.
Day 06 · Money/Shopping 15개 표현이 기본으로 들어 있습니다. Claude 밖에서 열면 설정에서 Anthropic API 키를 넣어야 사진 분석과 AI 회화가 동작합니다.
